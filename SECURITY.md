# Security and privacy boundaries

- Demo data is fictional and stored only in the browser via localStorage.
- There are no accounts, server-side writes, secrets, PII uploads or third-party requests.
- Do not use real workforce data on a public demo.
- This starter is not a secure multi-user, payroll or official attendance system.
- If integrating into a real product, implement server-side authentication, per-tenant authorization, audit logs, encryption where required, backups, data retention, and input validation.
- No government RSZ/Checkinatwork integration is included.
- Security issues: open a responsible disclosure issue without publishing exploit details or sensitive data.
